# arithmeticExp

[dowload the latest report here](https://jounaidayoub.github.io/arithmeticExp/rapport.pdf)

C project for infix arithmetic expressions to an expression tree.

## Build and Run

To build the project, run:
    
```sh
make
```

To execute the program after building:

```sh
make run
```
